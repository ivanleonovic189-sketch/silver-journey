# Эмоциональный интеллект в профессиональной деятельности инженера

Исходники презентации на ~30 минут (23 слайда) с блиц-опросом для класса.

- `deck.json` — оглавление: порядок слайдов, разделы, шрифты (Rubik + IBM Plex Sans).
- `slides/*.html` — по одному слайду на файл, формат 1920×1080, все стили инлайн.
  В каждом слайде `<aside>` — заметки докладчика: что говорить и сколько времени держать.

## Структура

| Блок | Слайды | Время |
| --- | --- | --- |
| Вступление и план | cover, hook, agenda | 3 мин |
| Что такое ЭИ | what, model | 5 мин |
| Зачем инженеру | myth, evidence, where | 5 мин |
| Три ситуации | review, incident, client | 8 мин |
| Приёмы и тренировка | tools, formula, develop | 5 мин |
| Блиц | blitz, q1–q5, key | 6 мин |
| Выводы | takeaways, end | 2 мин |

Ответы блица: 1 — Б, 2 — Б, 3 — Б, 4 — В, 5 — Б.

Перед выступлением заменить плейсхолдеры `[Имя докладчика]`, `[группа]`, `[дата]`, `[контакт]`
на титульном и финальном слайдах.

## presentation.html — самостоятельная версия

Один файл, открывается двойным кликом в любом браузере, интернет нужен только для
подгрузки шрифтов (без него подставятся системные, вёрстка не поедет).

| Клавиша | Действие |
| --- | --- |
| `→` `←` `PageUp` `PageDown` | листать слайды |
| `Пробел` | на вопросах блица — показать ответ, иначе следующий слайд |
| `S` | заметки докладчика внизу экрана |
| `F` | полный экран |
| `Home` / `End` | первый / последний слайд |

На сенсорном экране — свайп. Номер слайда сохраняется в адресе (`…/presentation.html#9`),
так что можно открыть сразу нужный.
