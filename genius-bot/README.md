# 🧠 Genius Routines Bot

Личный Telegram-бот (только Bot API, без MTProto), который:

1. **Напоминает о рутинах «становления гением»** по расписанию:

   | Рутина | Когда |
   |---|---|
   | ☀️ Утренний план на день | ежедневно 08:30 |
   | ✍️ Шаг 2 — «Нулевая рефлексия», 10 мин потока сознания | ежедневно 08:40 |
   | 🧠 Шаг 0 — аффирмация действия + сложная задача | ежедневно 09:00 |
   | 🎲 Этап 4 — решения «вслепую» | вт, сб 12:00 |
   | ⚡ Этап 2 — искусственное «чутьё» | ежедневно 13:00 |
   | 🔒 Шаг 3 — задачи с ограничениями | ежедневно 14:00 |
   | 🗣 Шаг 5 — обратная связь «чужой взгляд» | пн, чт 16:00 |
   | 👂 Этап 3 — сенсорная разгрузка 10 мин | ежедневно 18:30 |
   | 📚 Шаг 1 — хаотическое чтение с принудительной связкой | ежедневно 19:30 |
   | 📊 Этап 1 — записать 5–10 предчувствий | ежедневно 21:00 |
   | 😴 Шаг 4 — сон 7ч + вопрос на ночь | ежедневно 22:30 |

2. **Ведёт журнал предчувствий и мыслей** (`/note`), даёт отмечать сбылось/нет
   (`/check`) и считает точность твоей интуиции (`/stats`).
3. Под каждым напоминанием кнопка **«✅ Сделал»** — копится статистика по дням.

Владелец определяется автоматически: **первый, кто напишет боту `/start`**
(или задай `CHAT_ID` в `.env` явно).

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Регистрация владельца + список рутин |
| `/routines` | Прислать все рутины сейчас |
| `/morning` | Утренний план вручную |
| `/note <текст>` | Записать предчувствие / мысль / вопрос на ночь |
| `/check` | Отметить, какие предчувствия сбылись |
| `/stats` | Дни выполнения рутин + точность интуиции в % |

## Запуск

```bash
cp .env.example .env   # вставь BOT_TOKEN
pip install -r requirements.txt
python bot.py
```

Затем напиши боту `/start` — ты станешь владельцем, и напоминания пойдут тебе.

## Деплой (Docker, любой VPS)

```bash
cp .env.example .env   # вставь BOT_TOKEN
docker compose up -d --build
```

Важно сохранять папку `data/` — там БД со статистикой и владельцем.

## Бесплатный хостинг: Hugging Face Spaces (~10 минут)

Реально бесплатный способ держать бота 24/7 без карты:

1. Зарегистрируйся на [huggingface.co](https://huggingface.co).
2. **New Space** → имя любое → SDK: **Docker** → Blank → Public или Private.
3. Загрузи в Space все файлы этой папки (`Files` → `Upload files`):
   `bot.py, config.py, db.py, routines.py, requirements.txt, Dockerfile`.
4. Отредактируй `README.md` Space'а — в самом верху должна быть шапка:

   ```yaml
   ---
   title: genius-bot
   sdk: docker
   app_port: 7860
   ---
   ```

5. **Settings → Variables and secrets → New secret**: имя `BOT_TOKEN`,
   значение — токен от BotFather. (Опционально переменные `TIMEZONE`,
   `MORNING_HOUR`.)
6. Space соберётся и запустится. Напиши боту `/start`.
7. Чтобы Space не засыпал от неактивности: зарегистрируйся на
   [uptimerobot.com](https://uptimerobot.com) (бесплатно) и добавь HTTP-монитор
   на URL Space'а (`https://<user>-<space>.hf.space`) с проверкой раз в 5 минут.

⚠️ Нюанс бесплатного Space: при пересборке/перезапуске файловая система
обнуляется — статистика в `data/` может сброситься (владелец заново
регистрируется одним `/start`). Для вечного хранения статистики нужен
любой дешёвый VPS с диском.

## Настройка расписания

Времена рутин — в `routines.py` (поле `cron`), время утреннего плана —
`MORNING_HOUR`/`MORNING_MINUTE` в `.env`, часовой пояс — `TIMEZONE`
(по умолчанию `Europe/Moscow`).

> 🔐 Никогда не коммить `BOT_TOKEN` в репозиторий — он живёт только в `.env`
> (уже в `.gitignore`). Если токен засветился — перевыпусти через
> @BotFather → `/revoke`.
