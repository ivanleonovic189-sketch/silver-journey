# 🧠 Genius Routines Bot

Личный Telegram-бот, который:

1. **Напоминает о рутинах «становления гением»** по расписанию (контент из твоих скринов):
   - Шаг 0 — аффирмации действия («я решаю сложные задачи») — каждый день в 09:00
   - Этап 1 — сбор данных о предчувствиях — каждый день в 21:00
   - Этап 2 — искусственное «чутьё» — каждый день в 13:00
   - Этап 3 — сенсорная разгрузка 10 мин — каждый день в 18:30
   - Этап 4 — решения «вслепую» — вторник и суббота в 12:00
2. **Ведёт журнал предчувствий** (`/note`), даёт отмечать сбылось/нет (`/check`)
   и считает точность твоей интуиции (`/stats`).
3. **Замечает, когда ты проснулся** (опционально): MTProto-сессия твоего аккаунта
   ловит первую активность утром (прочитал чат / отправил сообщение) и бот присылает
   «доброе утро» + план на день.

> ⚠️ Обычный бот через Bot API **не видит** твой онлайн-статус — поэтому для
> пробуждения нужна юзер-сессия (Telethon). Это опционально: без `API_ID`/`API_HASH`
> бот работает просто как напоминалка.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Список рутин и команд |
| `/routines` | Прислать все рутины сейчас |
| `/morning` | Утренний план вручную |
| `/note <текст>` | Записать предчувствие |
| `/check` | Отметить, какие предчувствия сбылись |
| `/stats` | Дни выполнения рутин + точность интуиции в % |

## Настройка

1. Создай бота у [@BotFather](https://t.me/BotFather), получи `BOT_TOKEN`.
2. Узнай свой ID у [@userinfobot](https://t.me/userinfobot) — это `CHAT_ID`.
3. (Опционально, для «проснулся») на [my.telegram.org](https://my.telegram.org) →
   *API development tools* → получи `API_ID` и `API_HASH`.
4. Скопируй конфиг и заполни:
   ```bash
   cp .env.example .env
   ```
5. **Напиши боту `/start` первым** — иначе он не сможет писать тебе сам.

## Запуск локально

```bash
pip install -r requirements.txt
python bot.py
```

При включённом watcher'е первый запуск спросит номер телефона и код из Telegram —
сессия сохранится в `data/user_session.session`.

## Деплой (Docker, любой VPS)

```bash
# первый запуск интерактивно (нужно ввести код для MTProto-сессии):
docker compose run --rm genius-bot python bot.py
# Ctrl+C после успешного логина, затем:
docker compose up -d
```

Без watcher'а (только напоминания) можно сразу `docker compose up -d`.

Подойдёт любой хостинг с постоянным диском: VPS, Railway, Fly.io.
Важно сохранять папку `data/` (там БД и сессия).

## Расписание

Времена задаются в `routines.py` (поле `cron`), часовой пояс — переменной
`TIMEZONE` в `.env` (по умолчанию `Europe/Moscow`).

## Как работает «проснулся»

Telegram не сообщает сессии её собственный статус online, но присылает на все
твои устройства события активности: прочтение чатов (`UpdateReadHistoryInbox`)
и исходящие сообщения. Первое такое событие после `WAKE_AFTER_HOUR` (по умолчанию
после 04:00) считается пробуждением — раз в день бот присылает утренний план.
