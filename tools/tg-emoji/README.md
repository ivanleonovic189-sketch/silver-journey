# Чёрное сердце — премиум-эмодзи для Telegram

Анимированное кастом-эмодзи: чёрное сердце с рисунком углём внутри. Две версии
одной идеи.

**`noir` — объёмное сердце, без цветов.** Форма светится не заливкой, а
рельефом: из маски сердца строится карта высот, из неё — нормали, и дальше
считается настоящее освещение (Ламберт + блик Блинна-Фонга + Френель по краю).
Источник света ходит маятником по верхней полусфере, поэтому блик скользит по
поверхности, как по полированному камню. На каждом ударе сердце раскаляется
изнутри красным, вспыхивают глаза и наружу выбрасывает искры.

**`cartoon` — мультяшная, с венком из белых лилий.** Белая обводка, розовый
кант, упругий пульс со сплющиванием, моргающие глаза, звёздочки. Стебли лилий
обхватывают сердце сзади и смыкаются цветами спереди.

## Что на выходе

| Файл | Что это |
|---|---|
| `out/black_heart_noir.webm` | **эмодзи, объёмная версия** — 100×100, VP9 + альфа, 3 с, 30 fps, ≤ 64 КБ |
| `out/black_heart_cartoon.webm` | **эмодзи, мультяшная версия** — те же параметры |
| `out/preview_<стиль>_512.webm` | увеличенное превью для просмотра в браузере |
| `out/thumb_<стиль>.webp` | статичный кадр 100×100 |
| `out/still_<стиль>.png` | статичный кадр, увеличенный |

Формат соответствует требованиям Telegram к анимированным кастом-эмодзи:
VP9 с альфа-каналом, ровно 100×100, до 3 секунд, до 30 fps, до 64 КБ, без звука.
Битрейт подбирается автоматически — двоичный поиск по лимиту, с запасом в 2 КБ.

## Как подставить своё фото

Положите рисунок в `assets/monster.jpg` (подойдёт и `.png` / `.webp`) и запустите:

```bash
pip install pillow numpy imageio-ffmpeg
python3 generate_emoji.py                      # возьмёт assets/monster.*, обе версии
python3 generate_emoji.py --photo /путь/к/фото.jpg
python3 generate_emoji.py --style noir         # только одна версия
```

Фото обрабатывается автоматически: кадрируется по центру в квадрат, переводится
в «уголь» (светлая бумага убирается, штрихи остаются), а красные пятна на
рисунке распознаются как глаза и начинают пульсировать вместе с ударом сердца.
В объёмной версии рисунок дополнительно подчиняется освещению и слегка
съезжает при покачивании — как будто лежит на выпуклой поверхности. В
мультяшной он постеризуется: меньше полутонов, чётче пятна. Если фото нет,
рисуется процедурный монстр из `monster.py`.

Быстрый предпросмотр одного кадра без кодирования видео (секунды вместо минут):

```bash
python3 generate_emoji.py --still 8
```

## Как залить в Telegram

1. Откройте [@Stickers](https://t.me/stickers) → `/newemojipack`.
2. Введите название набора.
3. Отправьте `.webm` **файлом** (скрепка → «Файл», не «Фото» — иначе Telegram
   пережмёт его и не примет).
4. Пришлите эмодзи-подпись, например 🖤.
5. Повторите для второй версии → `/publish` → короткая ссылка набора.

Ставить кастом-эмодзи в сообщения может любой, у кого есть Telegram Premium.

## Настройка

Всё, что стоит крутить, собрано вверху `generate_emoji.py`:

- `STYLES` — размер и положение сердца, наличие венка и рельефа, палитра,
  амплитуда пульса, сплющивание, моргание, тип искр;
- `ALBEDO` / `LIGHT` / `SPEC` / `SSS` — материал объёмного сердца: собственный
  цвет, рассеянный свет, блик и жар изнутри;
- `build_normals()` — крутизна купола (коэффициент `k` задаёт, насколько резко
  заваливаются нормали, от него зависит размер блика);
- `beat_envelope()` — ритм пульса, `blink_factor()` — момент моргания,
  `bursts()` — разлёт искр.

Венок мультяшной версии задаётся в `lilies.render()`: цветы и бутоны
расставляются по эллипсу вокруг центра сердца в градусах. Радиус кольца меньше
единицы — цветы уходят под сердце, из-за чего и получается объятие.
